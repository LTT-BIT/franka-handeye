↗
  1. 固定标定板

    板与 FR3 link8 保持刚性连接。若由 Sharpa 夹持，整段采集期间保持抓握不变。

  2. 手动拖动机械臂

    使用 Franka 示教模式调整姿态；本程序只读，不发送运动命令。

  3. 松手，停稳，再采集

    等待至少 1 秒。绕至少两个不同轴变化约 20–40°，覆盖不同位置与距离。
